# Repository conventions

## Commit messages and pull requests
- Do **NOT** add any AI/assistant attribution to commits or pull requests.
  Specifically never include:
  - `Co-Authored-By: Claude ...` (or any Claude/Opus/Sonnet/Haiku co-author line)
  - a `Claude-Session:` trailer or any `claude.ai/code/session` link
  - a "Generated with Claude Code" / "🤖 Generated with ..." line
- Keep commit messages and PR descriptions clean and written in a normal human style.
